# Calculatrice

Calculatrice web élégante avec design glassmorphism, entièrement fonctionnelle avec support clavier.

## Fonctionnalités

- **Opérations de base** : Addition, soustraction, multiplication, division
- **Fonctions supplémentaires** : Pourcentage (%), inverse de signe (±), effacement (AC)
- **Support clavier** : Utilisez votre clavier pour taper les chiffres et opérations
- **Design glassmorphism** : Interface moderne avec effets de flou et transparence
- **Responsive** : S'adapte à toutes les tailles d'écran
- **Accessibilité** : Labels ARIA, navigation au clavier, prefers-reduced-motion

## Raccourcis clavier

| Touche | Action |
|--------|--------|
| `0-9` | Entrer un chiffre |
| `+` `*` `-` `/` | Sélectionner un opérateur |
| `Enter` ou `=` | Calculer le résultat |
| `.` ou `,` | Ajouter un décimal |
| `Backspace` | Supprimer le dernier chiffre |
| `Escape` | Tout effacer |
